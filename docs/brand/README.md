# Brand files

From `smoothvault-launch-kit.zip` (6 October 2026). These are for use outside the website: profiles, documents, print.

| File | Use |
| --- | --- |
| `profile-photo-1024.png` | Square profile picture for Google, Trustpilot, Facebook and WhatsApp Business |
| `logo-2000w.png`, `logo-reversed-2000w.png` | High-res logo for light / navy backgrounds: documents, email signatures |
| `app-icon-rounded-1024.png` | Rounded app-style icon |
| `review-qr.png`, `review-qr.svg` | QR code to `https://smoothvaultmoves.co.uk/review/`, used on the [review card](../review-card/index.html); use the SVG for print |

The vector logos (`logo.svg`, `logo-reversed.svg`, the one-colour `logo-mono-navy.svg` and `logo-mono-white.svg` for embroidery, stamps and vinyl, `mark.svg`, `mark-reversed.svg`, `app-icon.svg`) are in [`public/brand/`](../../public/brand). They are identical to the kit's copies.

The review request and reply messages from the kit's `review-messages.txt` are in the [launch playbook](../launch-playbook.md), Step 5.
